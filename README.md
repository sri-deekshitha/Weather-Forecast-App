# Weather_Application


A web-based weather prediction application built with **HTML, CSS, and JavaScript** **Visual Crossing Weather API** . The application retrieves live weather information from the and presents current conditions, forecasts, and weather highlights in a simple dashboard.

## Features

- Search weather information by city
- Automatically detects an initial city using public IP-based geolocation
- Displays current temperature and weather condition
- Shows precipitation information
- Displays a 7-day weather forecast
- Provides an hourly view for the current day
- Switches between Celsius (°C) and Fahrenheit (°F)
- Displays UV Index and UV status
- Displays wind speed
- Displays sunrise and sunset times
- Displays humidity and humidity status
- Displays visibility and visibility status
- Provides city autocomplete suggestions
- Changes weather icons and background images according to weather conditions
- Updates the displayed date and time automatically
